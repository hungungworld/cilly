# CILLY film v2 — 소스

`assets/cilly-film.mp4`(17.5초, 1080×1920, 30fps)를 만드는 코드. 화면은 전부 캔버스 모션그래픽으로
프레임 단위 렌더링하고, v1 영상에서는 자연스러운 컷 몇 개(스프레이 손, 타코 한입, 병+허브, 쌀국수)만 짧게 가져옴.

| 시간 | 장면 | 소스 |
|---|---|---|
| 0–2.0 | 세계 각국 "고수 많이요" 주문서 → MORE. | 신규 |
| 2.0–3.5 | 쌀국수에 고수 세 잎 개그 | 신규(일러스트) |
| 3.5–4.0 | SPRAY. | v1 컷 + 미스트 |
| 4.0–5.0 | 병에서 고수잎 폭발, CILANTRO, BOTTLED. | 신규 |
| 5.0–5.5 | BITE. (실시간 속도) | v1 컷 + 고수 부스러기 |
| 5.5–6.5 | 덮밥/쌀국수/연어 휩팬 몽타주 | 사진 + 미스트 |
| 6.5–7.5 | FRESHLY CUT. (칼로 자르는 타이포) | v1 컷 |
| 7.5–9.0 | 香菜 · BORN A FRAGRANCE. | 신규 |
| 9.0–10.0 | 2×2 분할 화면 칙! ×4 | 사진 + 미스트 |
| 10.0–10.5 | 아삭! | v1 컷 |
| 10.5–12.5 | REPEAT. ×1 → ×99 | 혼합 |
| 12.5–13.5 | 고수잎 비 · NEVER ENOUGH. | 신규 |
| 13.5–14.5 | 고수 많이, 이제 내 맘대로. | v1 컷 |
| 14.5–17.5 | 엔드카드 | 신규 |

오디오는 v1 비트(120BPM)를 유지하고, 스프레이·아삭·휙 효과음을 `audio.py`에서 새 컷에 맞춰 합성.

재렌더링: `./build.sh` (ffmpeg, node+playwright, python3+numpy 필요). 장면 수정은 `scene.js`.
미리보기: `.work`를 http로 띄우고 `index.html`에서 콘솔에 `renderFrame(프레임번호)`.
